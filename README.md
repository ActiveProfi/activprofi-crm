# АктивПрофи CRM

Текущая версия CRM студии — вариант B. Русскоязычный интерфейс для работы с лидами, проектами и задачами.

## Запуск

Требуется Node.js (проверено на Node.js 24). Установка зависимостей не нужна:

```sh
node variant-b/preview.cjs
```

Открыть http://127.0.0.1:3212/ . Сервер доступен только на локальном компьютере.

## Возможности

- Импорт Excel/CSV, распознавание нескольких телефонов, email, соцсетей и комментариев.
- Базы по группам результатов: «Прислать КП», «Перезвонить», «Не актуально», «Уже есть решение», «Отказ».
- Внутри каждой группы — отдельные базы с названием и датой исходного файла.
- Воронки → Загрузить лиды → группа → файл базы → этап. Контакты выбранной базы появляются отдельными карточками без повторной загрузки уже перенесённых контактов.
- Распределение по менеджерам, проекты, задачи, дорожные карты, онлайн-доска, роли и персональные права.
- Интерфейсы и подготовленные модели интеграций с телефонией, мессенджерами и Google Sheets.

## Статус

Это локальный UX-прототип, а не готовая серверная CRM. Данные сохраняются в localStorage и IndexedDB браузера. Переключатель ролей предназначен для проверки интерфейса и не является серверной авторизацией. Для совместной работы нужен backend с аутентификацией и проверкой доступа. Telegram, Sipuni, голосовой обзвон и отправка сообщений требуют отдельного подключения; наличие интерфейса не означает действующую интеграцию.

В репозитории только код, логотип и синтетические демонстрационные данные. Реальные базы лидов, переписка, записи звонков, внутренние документы и скриншоты с клиентскими данными не публикуются. Публикация исходников не создаёт общедоступный работающий сайт CRM и не копирует данные браузера.
